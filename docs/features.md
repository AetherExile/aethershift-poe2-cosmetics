# AetherShift Features Overview

This document details the cosmetic customization capabilities supported in **AetherShift** for Path of Exile 2.

AetherShift operates as a Windows application that applies real-time visual cosmetic modifications on your local client without altering account entitlement records or permanent game data.

---

## 🎨 Supported Cosmetic Categories

### 1. Character Skins
- Select and display supported character skin visual models and armor appearance sets.
- Preview cosmetic sets live on your active character.

### 2. Character Effects
- Select supported visual character auras and body effect overlays.
- Real-time visual switching during active gameplay sessions.

### 3. Back Attachments
- Select supported wings, capes and back attachments.
- Synchronized visual rendering with character movement.

### 4. Weapon Effects
- Apply supported weapon effects to equipped weapons.
- Visual weapon trails and particle glows.

### 5. Portal Effects
- Select and apply supported portal effects.
- Visual updates when opening town portals.

### 6. Cursor Customization
- High-visibility custom cursor presets designed to improve mouse tracking during intense gameplay.

### 7. Multi-Tier MTX Variants
- Access and preview progressive tier variations of multi-tier cosmetic items (Tier 1, Tier 2, Tier 3, etc.).
- Switch between different visual evolution stages directly within the application interface.

---

## 📌 Technical Scope & Entitlement Notice

- **Client-Side Rendering**: AetherShift modifies cosmetic visual representations locally on your client display.
- **No Entitlement Modification**: Using AetherShift does not grant permanent MTX ownership, add microtransactions to your Path of Exile account profile, or modify server-side database records.
