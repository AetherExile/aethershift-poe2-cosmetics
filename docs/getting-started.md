# Getting Started with AetherShift

Welcome to the **AetherShift** getting started guide. This document explains how to set up the application environment and connect with the official community.

---

## 🛠️ System Prerequisites

Before launching AetherShift, ensure your system meets the following prerequisites:

1. **Operating System**: Windows 10 (64-bit) or Windows 11 (64-bit).
2. **Game Client**: Path of Exile 2 installed via Steam or the Official Standalone Launcher.
3. **Display Settings**: For custom cursor rendering, Windowed or Borderless Windowed mode in Path of Exile 2 graphics options is recommended.

---

## 📥 Project Channels & Distribution

Software builds, compatibility updates, and community access management are centralized through official project channels:

1. 🌐 **Official Website**: Visit [aetherexile.com](https://www.aetherexile.com/) for official product announcements and version specifications.
2. 💬 **Official Discord Community**: Join the [Aether Exile Discord Community](https://discord.gg/nxGqxpHSdK) for:
   - Official download packages.
   - Information regarding planned **2-hour trial key availability**.
   - Notifications when compatibility updates are released following Path of Exile 2 patches.

---

## 🔑 Trial & Licensing Framework

- **2-Hour Trial Offer**: A 2-hour trial evaluation key is a planned product offer. Trial key availability and distribution schedules are announced operationally within the official Discord community.
- **License Keys**: Premium access keys provide continuous application functionality.
