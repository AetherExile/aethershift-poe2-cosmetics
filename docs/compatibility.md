# System & Client Compatibility Matrix

This document outlines the verified operating system environments and game client configurations supported by **AetherShift** for Path of Exile 2.

---

## 🖥️ Operating System Compatibility

| Operating System | Architecture | Compatibility Status | Notes |
| :--- | :--- | :--- | :--- |
| **Windows 10** | 64-bit | ✅ Supported | 64-bit Windows operating system required |
| **Windows 11** | 64-bit | ✅ Supported | 64-bit Windows operating system required |
| **macOS / Linux** | N/A | ❌ Not Supported | Windows desktop environment required |

---

## 🎮 Game Client Compatibility

| Client Type | Platform | Compatibility Status | Notes |
| :--- | :--- | :--- | :--- |
| **Steam Client** | Steam / Grinding Gear Games | ✅ Supported | Path of Exile 2 on Steam |
| **Official Standalone Launcher** | Grinding Gear Games | ✅ Supported | Official launcher from pathofexile.com |

---

## 🚫 Platform Exclusions & Unverified Systems

- **Path of Exile 1**: Path of Exile 1 is not supported.
- **Regional Launchers**: Kakao and Tencent regional client distributions are unverified and not supported.
- **Console Platforms**: PlayStation 5 and Xbox Series X/S versions are not supported.
