# Troubleshooting & Support Guide

This guide helps resolve common display and compatibility questions when running **AetherShift** for Path of Exile 2.

---

## 🛠️ Common Display & Compatibility Guidance

### Issue 1: Custom cursor is not visible in-game
- **Possible Cause**: Path of Exile 2 is running in Exclusive Fullscreen display mode.
- **Solution**: Open Path of Exile 2 Options ➔ Graphics ➔ Display Mode. Change from **Exclusive Fullscreen** to **Borderless Windowed** or **Windowed**.

### Issue 2: Application needs a compatibility update after a game patch
- **Cause**: Grinding Gear Games updated the Path of Exile 2 client.
- **Solution**: Check the official [Discord Community](https://discord.gg/nxGqxpHSdK) for notice of released compatibility updates following Path of Exile 2 patches.
